## Proyectos

#### [APISENSOR](https://github.com/IDS-HUGO/APISENSOR) — `Go · MySQL · RabbitMQ`
Backend para sistemas IoT con arquitectura hexagonal estricta. Gestión de sensores, mensajería asíncrona con RabbitMQ y persistencia en MySQL. Separación clara de capas: dominio, aplicación e infraestructura.

#### [WEBSOCKET_EASYGROW](https://github.com/IDS-HUGO/WEBSOCKER_EASYGROW) — `Go · WebSocket · MQTT`
Módulo de comunicación en tiempo real entre sensores físicos y el frontend. Ingesta de datos vía MQTT y transmisión al cliente con baja latencia mediante WebSocket.

#### [API-FRONT-EASYGROW](https://github.com/IDS-HUGO/API-FRONT-EASYGROW) — `FastAPI · MySQL · React.js`
Plataforma educativa modular con API RESTful, autenticación JWT y frontend desacoplado en React. Arquitectura orientada a mantenibilidad y escalabilidad.

#### [GYM-SYSTEM](https://github.com/IDS-HUGO/GYM-SYSTEM) — `Java`
Sistema de gestión de membresías, usuarios y reportes para gimnasio desarrollado en Java orientado a objetos.
